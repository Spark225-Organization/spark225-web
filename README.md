# spark225.com

Copia estática del sitio de Spark225, servida con GitHub Pages.
Se generó el 24 nov 2026 a partir del WordPress actual: 49 páginas reales en español e inglés, sin la tienda ni las páginas demo de la plantilla.

- El formulario de contacto abre el correo del visitante, dirigido a contacto@spark225.com, con sus datos ya escritos.
- El correo (Google Workspace) y SCORE no dependen de este repositorio.
